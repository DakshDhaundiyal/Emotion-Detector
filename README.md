# Emotion Detector

## Project Description

Emotion Detector is an AI-based web application that analyzes text and identifies the emotions expressed in it. The project uses the Watson NLP library for emotion detection and provides a Flask-based web interface.

## Project Name

**Emotion Detector**

## Features

- Detects anger, disgust, fear, joy, and sadness from text
- Identifies the dominant emotion
- Formats emotion scores in a clear output
- Provides a Flask web application
- Includes error handling for invalid input
- Includes unit tests
- Supports static code analysis with PyLint

## Technologies Used

- Python
- Watson NLP
- Flask
- unittest
- PyLint
- Git and GitHub

## Project Tasks

1. Clone the project repository
2. Create an emotion detection application using the Watson NLP library
3. Format the output of the application
4. Package the application
5. Run unit tests on the application
6. Deploy the application using Flask
7. Incorporate error handling
8. Run static code analysis
